# Holopix 出图工作流（给《东莱岛》20 人立绘用）

> 目标：20 个角色 × 6 个场景（日常/害羞/本垒/阴险/爽上天/专注）= 120 张立绘差分，
> 风格统一、同一角色不同图之间脸不换人。
> 下面的操作在 Holopix（holopix.cn，游戏美术向 AI 平台）里完成；界面以实际为准，功能名可能微调。

## 一、先用 10 分钟把流程跑通

1. **注册登录**：holopix.cn，手机号注册。新用户送算力、每天有免费次数（以官网为准）。
2. **选一个"底模"先定死**：模型广场里挑一个二次元游戏立绘向的模型（例如国风二次元 / 赛璐璐类），
   把它当成整个项目的唯一风格基准。**整包 120 张都用它，中途不要换。**
3. **做一张"风格锚点"**：选一个最好画的角色（建议**莱拉**，造型特征最明确），
   用「一键成稿」→ 选底模 → 填提示词 → 出 20 张 → 挑 1 张最满意的，作为全项目的风格锚点。
4. **用锚点图派生**：之后每个角色都上传这张锚点图作为「参考图」，只改角色特征词，不改变画风词。
5. **满意后精修**：局部重绘改表情/手，高清放大到 2K/4K，导出 PNG。
6. **接进游戏**：按下面的命名放进 `assets/characters/<id>/`，在 `characters.json` 填 `texture`。

## 二、怎么让 20 张图保持同一种风格

核心就一句话：**先定一个风格基准，之后所有图都以它作为参考输入向外派生**（链式派生，而不是各画各的）。

具体五条：

1. **固定底模**：同一批图用同一个模型 + 同一套参数（尺寸、采样步数、CFG）。换模型 = 换画风，必漂移。
2. **固定风格后缀**：在你的提示词末尾永远追加同一串风格词，例如：
   `赛璐璐上色, 干净线稿, 二次元游戏立绘, 半身构图, 柔和光影, 高细节, 清晰的面部, 纯色背景`
3. **固定负向词**：同一串负向词，避免某几张突然冒出写实/3D 质感：
   `低质量, 模糊, 畸形, 多手指, 多肢体, 面部扭曲, 结构错误, 比例失调, 文字, 签名, 水印, 边框, 真人照片, 3D渲染, 塑料质感, 过度暴露`
4. **统一尺寸/比例**：立绘统一 1024×1536（2:3）。半身或全身二选一，别混着出。
5. **要更稳就训练专属模型**：把满意的 20–30 张同风格图上传「模型训练」，设触发词（如 `donglai_style`），
   之后每次带上触发词，比纯提示词稳得多。

> 角色之间的一致性，靠"角色锚定串"：每个角色的发型、发色、瞳色、标志物（如莱拉的护目镜、洋洋的定制琴）
> 在每个场景里逐字重复，不能改写。见 `docs/holopix_prompts.csv` 的"正向提示词"列。

## 三、已经满意的图，怎么改动作 / 表情

按"改动大小"从轻到重选工具：

| 想改什么 | 用什么 | 操作要点 |
|---|---|---|
| 只改表情（笑/害羞/阴险/张嘴） | **局部重绘** | 框选脸部（含眉眼嘴），提示词只写表情词，如 `害羞，脸红，视线躲闪，抿嘴`；重绘幅度 0.3–0.5，避免脸型跑掉 |
| 改手部姿势（托腮、抓衣角） | 局部重绘 | 框选手部 + 少量手臂，提示词写 `手托腮`/`手指抓衣角`；手部崩就多跑几次挑一张 |
| 改整体动作/站姿/半身转全身 | **姿态生图 / ControlNet（OpenPose）** | 上传一张姿势参考图（或平台里选姿态模板），开启 ControlNet，把角色图设为「参考图」，提示词里保留角色锚定串；重绘幅度 0.5–0.65 |
| 改构图/景别（半身→近景） | 图生图 + 低重绘幅度 | 重绘幅度 0.3–0.4，配合局部重绘补细节 |
| 只改颜色/服装细节 | 局部重绘或智能替换 | 框选服装区域，写 `换成黑色高领` 之类，幅度 0.4 左右 |
| 改视角（正面→侧 45°） | **2D 转 3D 视角转换** | 平台自带，输出现有图的侧视角，再用局部重绘修脸 |
| 加背景/扩画布 | **智能扩图** | 先扩图，再单独生成背景，别在扩图里塞人物 |
| 拆分层供 Live2D/骨骼用 | **智能拆补图层** | 导出 PSD，人物/头发/表情分层 |

**一句话版**：脸别重生成，永远用"局部重绘 + 参考图"；动作用"姿态/ControlNet"；表情用"框脸重绘"。
整张图重跑 = 换脸风险最大。

## 四、和 Godot 工程对接

### 文件命名

```
assets/characters/
  leila/    normal.png  shy.png  intimate.png  sinister.png  excited.png  focus.png
  yangyang/ ...
  jiaoguan/ ...
```

### 填进 characters.json

```json
{"id": "leila", "name": "莱拉", "type": "假小子·电焊工", "color": "#e08a4a",
 "texture": "res://assets/characters/leila/normal.png",
 "expressions": {"shy": "res://assets/characters/leila/shy.png"}}
```

游戏界面已经支持：`characters.json` 里填了 `texture` 就显示立绘，没填就显示占位卡；
`scenes.json` 的 `texture` 同理（背景图）。

### 场景图

```
assets/scenes/island_day.png  island_dusk.png  quake_red.png  villa_night.png  warship.png
```
对应 `data/scenes.json` 里给每个场景补 `"texture": "res://assets/scenes/xxx.png"`。

## 五、建议的执行顺序（省算力）

1. **试点 3 人**：莱拉（假小子）、洋洋（男娘·富家千金）、教官（大姐姐）——正好是三个可攻略对象。
   每人只出「日常 / 害羞 / 专注」3 张，先把风格锚点、参考图、局部重绘的流程跑顺。
2. **定型**：确定底模 + 风格后缀 + 参考图策略，必要时训练专属模型。
3. **批量**：按 `holopix_prompts.csv` 逐行出图，每个场景出 4 张挑 1 张。
4. **差分**：满意的图用局部重绘批量做表情差分，而不是重新生成。
5. **导出**：高清放大 → 抠图去底 → 按命名放进工程 → 改 JSON。

## 六、常见坑

- **手崩**：半身像尽量让手出画（提示词写 `hands out of frame`），或者局部重绘手部多跑几次。
- **风格漂移**：换了模型/尺寸/风格词就会漂，整批必须同一套配置。
- **身份串**：多人同框时用"图1/图2"明确指代，参考图只放一张主参考。
- **局部重绘接缝**：框选区域要比目标大一圈，重绘幅度别超过 0.6。
- **颜色被参考图带跑**：参考图权重调低，或把服装颜色写进提示词并加强。

## 七、这份包里的配套文件

- `docs/holopix_prompts.csv`：20 角色 × 6 场景共 120 条提示词（正向/负向/尺寸），可直接照着填。
- `export/20角色设计_Holopix图集.md`：每个角色的外观 tag、六场景的表情/肢体/心理描写。
