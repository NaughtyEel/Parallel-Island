# 平行之岛 — 设计概要（骨架版）

## 一句话

表面是吉他群的年度合奏旅行，实际是一次「世界线跃迁事故」；玩家每死一次，就被「联合会」送回上岛那天。

## 三周目结构

| 周目 | 玩家知道什么 | 结局走向 | 目的 |
|---|---|---|---|
| 一周目 | 以为只是地震+连环凶案 | 无论怎么选都会全灭（严惩路线直接触发） | 让玩家目睹「不可挽回」，建立重来动机 |
| 二周目 | 知道会死人，开始怀疑军舰 | 「湮灭」：世界线排斥导致全岛物质消失；或提前发狂死亡 | 把调查焦点从"谁是凶手"转向"这座岛是什么" |
| 三周目 | 知道第二名死者是教官，必须先救她 | 带教官登上搁浅军舰，学会「相干涨落锚定仪」，把整座岛送回去 | 破局 |

分支树会记录每个分支点；二周目后可用「从此刻重来」直接回到关键节点，而不必重跑整条线。

**第 5 周目**起，联合会会放出关于「恶意存在」的档案（见 `docs/设定集.md` 第五节）：
一切之机器 → 无限接近「一切存在」→ 守恒分裂出无限接近「一切不存在」的反存在 →
超文明被瞬间湮灭，遗迹成为空泡。此后每次回溯，都是在评估人类值不值得继续被观测。

## 世界观要点

- **真空本征涨落**：所有粒子在普朗克尺度上的固有量子抖动。
- **退相干经典锁定**：宏观物质因环境耦合被锁定在唯一经典世界线上，表现为"历史不可改"。
- **相干涨落锚定仪**：在球形空间内强行同步所有粒子的涨落相位，让整体脱离当前世界线，滑入目标分支。
- **等容空间置换**：传送是双向等体积交换，物质不重叠、质量守恒。
- **6.5 级地震**：相位叠加期（约 22 秒）的晶格震颤 + 低频重力波，无闪光、无撕裂，普通人只会以为是地震。
- **副作用**：眩晕、恶心、重影、短暂虚化；反复跃迁者患「相位漂移症」，能短暂穿过固体。
- **联合会**：外星文明的观测组织；地球唯一有价值的资源是「文化」，直接接触会破坏文化连续性，因此只做隐蔽观测。玩家死亡后的意识被其捕获并回溯。
- **入侵者**：军舰里那台仪器被不明存在入侵后误启；十三兆年前已有文明因其毁灭。它就是「让人类陷入黑暗」的那只手。

## 角色与攻略对象

- 可攻略 3 人：**后备箱**（假小子·电焊工）、**洋洋**（男娘·富家千金音乐生）、**吉娘姐**（知性大姐姐，原名"我学吉他就是为了男娘啦啦啦"，群友简称吉娘姐）。
- 首名死者按「互动最多」动态判定（好感度最高者），候选池：后备箱 / 洋洋 / 莫邪 / 小万。
- 第二名死者固定为吉娘姐，用于二周目"必须救她"的动机。
- **岛上 12 人**：后备箱、洋洋、吉娘姐、茜师傅、牢 J、東清、八级大狂风、副驾驶、小万、希腊奶、汉灵帝、莫邪。
- **群聊 8 人**（只在对话框出场，零立绘成本）：狗王、副驾驶回应了你的消息、8J、无名、junzchen、怀揣、高纯度铋、Time limit。
  他们"不来岛上"本身就是伏笔——后期可以变成"岛外也失联了"的恐怖信号。

## 序章流程（已实现）

上岛 → 寒暄 → 帮谁搬器材（好感度分歧）→ 排练 → 晚餐（好感度分歧）→ 看见军舰 → 6.5 级地震 →
首名死者（动态）→ 第二具尸体（固定教官）→ 抉择：严惩（全灭）或调查（二周目入口）。

## 技术结构

- `data/story/*.json`：剧本节点，线性执行 + 标签跳转，分支点自动打快照。
- `data/characters.json` / `scenes.json` / `props.json`：角色、场景（含天光）、道具登记表；填 `texture` 即可换成真图。
- `autoload/`：GameState（世界线状态）、SaveManager（槽位与跨周目分支）、StoryDB（数据加载）、Settings（字幕/速度）。
- `ui/`：标题、游戏主界面（舞台 + 字幕 + 选项 + 存读档 + 日志）、分支树。
